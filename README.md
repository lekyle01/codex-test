# Hydration Tracker

A small web app to track how much water you drink each day.

## Features

- Set a daily water goal (in milliliters)
- Add water quickly with preset buttons or a custom amount
- See a progress bar for today's intake
- View the last 7 days of intake history
- Data persists in browser `localStorage`

## Run locally

```bash
python3 -m http.server 4173
```

Then open <http://localhost:4173> in your browser.
